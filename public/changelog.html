新增 优化 修复

忘记密码邮箱重置与前台登录组件优化

新增通过邮箱验证码重置忘记密码的功能，提升账户安全性；优化会员中心登录与注册面板展示，采用选项卡切换降低界面复杂度；修复 RSSHub 管理员后台版本匹配解析的正则缺陷。

  • 会员中心登录页面新增「忘记密码」入口，支持通过 SMTP 发信服务向用户邮箱发送 6 位数验证码，输入验证码即可重置新密码
  • 登录与注册表单整合为选项卡（Tab）切换展示，不再同时显示两个表单，界面更加清爽直观
  • 修复后台 RSSHub 状态检查中 cheerio 解析 Git Hash 的正则匹配在多行 HTML/空格时的失效问题
  • 完善帮助中心与 README / Docker 部署说明文档，补全密码重置机制说明与清理系统无用冗余缓存/备份
2026-05-29
新增 优化 修复

网页自动订阅、抓取模板和内置特殊路由

增强普通网页添加能力，支持自动发现 RSS/Atom/JSON、识别网页内嵌 JSON、套用后台抓取模板，并在套餐允许时尝试 RSSHub 特殊路由。后台内容页同步重新排版，抓取模板改为列表展示，添加和编辑统一进入弹窗。

  • 添加网页地址时会保存匹配到的 HTML / JSON 抓取规则，订阅源设置中可继续微调
  • 后台新增可编辑抓取模板列表，支持 HTML 选择器、JSON 路径、POST 请求体、共享 Cookie 和测试
  • 后台支持 AI 生成抓取模板草稿，并为掘金、知乎热榜等常见页面补充本地兜底规则
  • Compose 开发环境内置 RSSHub 和 Redis，支持后台配置多个特殊路由基址和检查规则版本
  • 会员套餐增加特殊路由权益，前台添加订阅时会显示可用 RSSHub 候选
  • 修复直接 RSS 地址去重过宽的问题，同一站点不同 RSS 地址可分别添加
  • 优化后台内容管理、版本检查和前台添加订阅布局，修复长 URL、正则和摘要导致的横向溢出

  • 帮助中心补充大量订阅、公开分享、邮件简报和隐私安全说明

  • 清理本地系统临时文件，并确认数据库与备份不会进入构建上下文
