快速入门

如何开始使用？

先在会员中心注册或登录账号，然后进入阅读中心添加订阅源。免费版最多支持 5 个订阅源，升级专业版后可添加更多。

阅读中心和会员中心有什么区别？

阅读中心负责订阅管理、文章列表和 AI 处理功能；会员中心负责账号登录、套餐升级、账单管理、兑换码和自定义 AI 配置。两者各自独立，职责清晰。

免费版有哪些限制？

免费版订阅上限为 5 个，不包含 AI 翻译、AI 总结和自定义 AI 接口功能。免费版可长期使用，没有时间限制。

订阅与内容

如何添加订阅源？

在阅读中心点击「添加订阅」，粘贴 RSS / Atom / JSON Feed 或普通网页地址。系统会先自动发现页面里的订阅源；如果网页只有内嵌 JSON 数据，会尝试识别列表、标题、链接、日期、摘要和正文路径，并写入该订阅的高级抓取配置。支持批量导入，也可以通过 OPML、JSON、TXT 文件批量导入订阅源。

文章正文抓取失败怎么办？

部分网站限制了自动抓取，可以点击「抓取正文」手动触发。如果持续失败，可能是网站本身不支持，建议查看原文链接。

如何筛选只看未读文章？

阅读中心顶部有筛选器，支持按全部 / 未读 / 已收藏筛选，也可以按订阅源、时间范围进一步筛选，快速定位目标内容。

订阅源很多会不会卡？

订阅源列表会先显示前 80 个，底部可继续加载更多。搜索、分类、未读、异常、公开状态等筛选仍会作用于全部订阅源，只是页面不会一次性渲染过多行。

如何公开分享订阅源？

在阅读中心打开订阅源设置，将分享状态设为公开。公开后该订阅源会出现在订阅广场；私有订阅不会进入广场展示。

网页订阅与特殊路由

普通网页也能订阅吗？

可以先直接添加网页地址。Z7 RSS 会按顺序尝试 RSS/Atom/JSON 发现、后台抓取模板、网页内嵌 JSON 自动识别，以及符合套餐权益的特殊路由。能识别时会自动保存可微调的抓取配置；不能识别时会提示原因。

什么是特殊路由？

特殊路由是通过 RSSHub 等路由服务把不提供 RSS 的网站转换为订阅源。添加订阅时如果当前网址有可用路由，并且你的套餐支持，会在「特殊路由」下拉框中显示候选；可选自动、指定某个基址，或不使用特殊路由。

前台高级抓取设置什么时候用？

当系统已经创建了订阅源，但标题、链接、摘要或正文不准确时，打开订阅源设置里的高级抓取。可以调整请求模式、备用 Feed 地址、请求方法、Cookie、HTML 选择器、JSON 路径、正文范围和登录表单。

后台抓取模板有什么用？

管理员可以在后台内容管理里维护抓取模板。模板按输入网址的正则自动匹配，适合一个站点或一类页面反复使用。添加和编辑都在弹窗中完成，列表页只展示模板名称、启用状态、格式、请求方式和匹配规则。

AI 生成抓取模板怎么用？

后台配置可用 AI 后，在抓取模板弹窗里输入待分析的网址，点击「AI 生成草稿」。系统会抓取网页样本并让 AI 生成 HTML 或 JSON 规则；生成后请先测试模板，确认首条标题、链接和正文正确再保存。

需要 Cookie 的网站怎么处理？

单个订阅源可以在高级抓取中填写 Cookie。后台抓取模板也支持共享 Cookie，适合管理员统一维护登录态；共享 Cookie 只在服务端加密保存，不会在前台回显给普通用户。

AI 功能

AI 翻译支持哪些语言？

专业版和团队版支持任意语言翻译，具体效果取决于所配置的 AI 模型。OpenAI、Claude、DeepSeek 等主流模型均支持多语言翻译。

自定义 AI 接口如何配置？

在会员中心进入 AI 配置页面，可以设置 API Base URL、API Key、模型名称、翻译提示词和总结提示词。配置后所有 AI 功能将使用你指定的接口。

AI 总结有什么用？

长篇文章可一键生成摘要，快速了解文章核心内容，判断是否值得阅读全文。摘要独立存储，随时可以回顾。

AI 邮件简报怎么配置？

在会员中心创建简报规则，选择全部订阅、指定分类或指定订阅源，设置发送时间、提示词和接收邮箱。后台 SMTP 配置完整后，系统会按规则自动生成并发送简报。

免费版可以用 AI 吗？

不可以。免费版不含 AI 翻译与 AI 总结功能，需要升级到专业版或团队版才能使用。

套餐与账号

如何升级套餐？

在会员中心选择需要的套餐，完成支付后立即生效。升级后订阅上限、AI 能力等权益立即可用，无需等待。

可以用兑换码吗？

可以在会员中心的兑换码入口输入兑换码，兑换成功后套餐权益立即追加到你的账号，有效期叠加。

如何联系客服？

登录后通过会员中心页面底部的联系方式与我们取得联系，工作时间内会尽快回复。

忘记密码了怎么办？

如果您在登录时忘记了密码，可在登录框下方点击『忘记密码？』，输入您注册时的邮箱地址。系统会向您的邮箱发送一个 6 位数验证码，在页面输入该验证码及新密码即可完成重置。*注：此功能需要系统管理员在管理后台正确配置 SMTP 发信服务。*

隐私与安全

API Key 和邮箱密码会明文显示吗？

不会。AI Key、翻译 Key、SMTP 密码和订阅源抓取密码会加密存储；页面只显示是否已配置。留空提交会保留原值，按页面提示清空才会删除。

哪些数据属于敏感数据？

用户邮箱、订阅地址、文章内容、会话记录、简报收件邮箱、抓取 Cookie、加密后的 Key 和数据库备份都应按生产数据处理，不建议公开分享。

部署时有哪些安全建议？

生产环境请更换高强度 APP_SECRET，使用 HTTPS，限制 data 目录权限，定期备份数据库，并避免把 .env、data 目录、日志和数据库备份提交到仓库。
